02 — WORKING ENGLISH

Clear > Fluent.

Native speakers value precision over pretty sentences. If your idea is clear, you've passed the bar.

02 — WORKING ENGLISH

Three tips.

/ Tip 01

Copy your closest colleague's sentence patterns

Everyone has go-to phrases. Borrow them.

/ Tip 02

Use AI to polish — not to write

Draft yourself first. Then clean it up. Read it back in your own voice.

/ Tip 03

Have a "How are you?" answer ready

Two sentences. Recent and real. It's how you actually warm up a working relationship.

02 — THE GOOD
/ Good 01

Way less hierarchy.

You can push back on your manager — and you're usually encouraged to. Frame it as a suggestion. Show your reasoning.

02 — THE GOOD
/ Good 02

Work-life balance is real.

Work hard when you're on. When you're off — actually be off. I once logged on at 2am and got called out for it.

02 — THE GOOD
/ Good 03

They treat you like an adult.

They respect your expertise and your time. In return: be accountable. Own your decisions.

02 — THE HARD
/ Hard 01

They are very polite.

"Sounds interesting." = please change this. My MA professor said "great work" every meeting — then gave me 60%.

02 — THE HARD
/ Hard 02

Self-discipline is your ticket.

Nobody checks in. Log what you did. Sync regularly. When you have a problem — bring a solution, not just a question.

02 — THE HARD
/ Hard 03

Things move slower.

Buffer every deadline. "I'll get back to you soon" does not mean today. Unexpected things happen more than you expect.

02 — WORKING CULTURE

Local vs foreign.

Foreign / Remote

  • Flexible hours
  • Flat hierarchy — you can push back
  • High autonomy
  • Designer voice respected

Local / Traditional

  • Fixed hours
  • Clear reporting structure
  • More hand-holding available
  • Easier to build in-person trust
No better or worse — only fit.

04 — IMAGE

Images — before vs after.

Before AI

  • Hunt for reference images
  • Photoshop collage / manual edit
  • Hours to get a rough concept

After AI

  • Write prompt → generate → refine
  • Minutes to usable concept image
  • Photoshop / Figma for finishing
04 — IMAGE

My image process.

  1. Feed reference to Claude → get a precise prompt
  2. Drop prompt into Freepik (with reference image)
  3. Finish in Photoshop / Figma — add type, fix details
04 — IMAGE

Image tools.

/ Use

Freepik · Midjourney

Fast first drafts. Use nano-banana or GPT-image-2 models.

/ Know this

Generated = not editable

AI output is a starting point. Always finish in Photoshop or Figma — you can't edit the pixels directly.

04 — VIDEO

Video — before vs after.

Before AI

  • Shoot footage or find stock
  • Manual edit in Premiere / Final Cut
  • Days for even a short clip

After AI

  • Node-based generation per segment
  • Stitch outputs together
  • Hours, not days
04 — VIDEO

Freepik Spaces —
node canvas.

  1. Storyboard first — one node per scene
  2. Each node output feeds the next node
  3. Export segment by segment, assemble in editor
04 — VIDEO

Video tools.

/ Model

Kling 3.0

Consistent motion, follows prompts well. Struggles with complex shots and long clips.

/ Voiceover

Record yourself

AI voices aren't polished enough for important work yet. Do it yourself.

/ Edit

CapCut · Premiere

Learn basic cuts. You're stitching generated segments — not doing full production.

04 — WEB

Web — before vs after.

Before AI

  • Write code manually
  • Or outsource to a developer
  • Weeks for a basic site

After AI

  • Designer builds the whole site
  • Design + code in one pipeline
  • Days, not weeks
04 — WEB

Web — 3-step flow.

  1. Google Stitch — rough template, explore styles
  2. Claude Code plan mode — iterate systematically
  3. Figma + paper — fine-tune details by hand
04 — WEB

Claude Code —
order matters.

  1. Setup environment → header / footer
  2. Homepage → other pages one by one
  3. UI done → wire up functions
  4. Visual confirmed → add animation + polish
Always use plan mode first.
